# econ5560-replication-kareht
## ECON 5560 Replication

Purpose: This code replicates the results from the paper "Non-Market Values in a Cost Benefit World: Evidence from a Choice Experiment" by Eppink et al 2016.

Data: The file titled S1Table.DTA provides the data that was published by the authors.

Installation: Should be able to run either run_all.py of replication.ipynb provided that you have installed all the packages listed below.

Packages/Dependencies: Numpy, Pandas, Matplotlib, Statsmodels
